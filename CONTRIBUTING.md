# Contributing to Project-4o

Thanks for your interest in contributing. This project is built by the community, and every contribution helps.

## How to Contribute

### Report Issues
- Check existing issues first to avoid duplicates.
- Include clear steps to reproduce, expected vs actual behavior, and your environment.

### Submit Pull Requests
1. Fork the repository and create a feature branch.
2. Make your changes with clear, focused commits.
3. Open a pull request with a descriptive title and summary of what changed and why.

### Join Discussions
- Use GitHub Discussions or the [r/project4o](https://www.reddit.com/r/project4o/) community for ideas, questions, and feedback.

## Areas We Need Help

- **Model training** — fine-tuning, dataset curation, evaluation
- **Tooling** — scripts, training pipelines, inference wrappers
- **Training data** — conversation examples, personality design, tone refinement
- **Testing** — try models, report bugs, suggest improvements
- **Documentation** — guides, examples, README improvements

## Guidelines

- Keep it respectful and constructive.
- Focus on small, reviewable changes per pull request.
- When in doubt, open an issue to discuss before investing significant time.
