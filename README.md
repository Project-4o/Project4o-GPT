# Project-4o

An open-source project to recreate a 4o-like AI.

## Goal
Build an AI with:
- personality
- natural conversation
- RP (roleplay) mode
- less rigid behavior

## Philosophy
This is NOT about the biggest model.
This is about the best experience.

## Plan
- Start with small models (3B–7B)
- Fine-tune using LoRA
- Focus on personality and interaction
